วิธีสร้าง GitHub Token สำหรับผู้ดูแล

ทำครั้งเดียว ใช้ Token นี้ login ที่หน้า ตั้งค่า Wi-Fi QR Code

  1. เข้าสู่ระบบ GitHub ด้วยบัญชีที่เป็นเจ้าของหรือมีสิทธิ์แก้ไข repo sutdetsnr.github.io
  2. เปิด github.com/settings/personal-access-tokens/new
  3. Token name: ตั้งชื่อ เช่น wifi-admin
  4. Expiration: เลือกวันหมดอายุ (เช่น 1 ปี) เมื่อหมดอายุให้สร้างใหม่
  5. Repository access: เลือก Only select repositories แล้วเลือก sutdetsnr.github.io เท่านั้น
  6. Permissions > Repository permissions > Contents: เลือก Read and write (ไม่ต้องเปิดสิทธิ์อื่น)
  7. กด Generate token แล้วคัดลอก Token ที่ขึ้นต้นด้วย github_pat_ เก็บไว้ในที่ปลอดภัย
  8. นำ Token ไปวางในหน้า login ของผู้ดูแล

ข้อควรรู้

  • Token ใช้แทนรหัสผ่านผู้ดูแล ห้ามส่งให้คนอื่นหรือโพสต์ไว้ในที่สาธารณะ
  • ถ้าเลือก "จำการเข้าสู่ระบบบนเครื่องนี้" Token จะถูกเก็บในเบราว์เซอร์ ใช้เฉพาะเครื่องส่วนตัว และกด "ออกจากระบบ" ทุกครั้งเมื่อใช้เครื่องสาธารณะ
  • ถ้าสงสัยว่า Token หลุด ให้ลบทิ้งที่ GitHub Settings แล้วสร้างใหม่
  • หลังบันทึก หน้า wifi.html จะอัปเดตภายในประมาณ 1 นาที (GitHub Pages ต้องสร้างเว็บใหม่)
  • รหัส Wi-Fi อยู่ใน QR Code และในไฟล์ wifi.json ที่เปิดดูได้แบบสาธารณะ ระบบ login มีไว้กันคนอื่นแก้ไข ไม่ได้ซ่อนรหัส Wi-Fi
